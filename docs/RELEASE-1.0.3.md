# 名将浮窗助手 1.0.3 · 公开测试版

## 下载与运行

普通用户下载 **MjsOverlay-1.0.3-win64.zip**，完整解压后双击最外层 **launch.cmd**。内置Python、OCR模型及本地榜单，无需单独安装Python。Windows 11 x64为已验证开发环境；Windows 10保留兼容支持，但尚未完成真实机器实战验收。

已安装用户退出助手后运行原包最外层launch.cmd检查更新。软件更新通道以仓库main上的签名清单为准；只创建Release不会启用更新。国内镜像的版本与完成状态单独披露。

## 使用前请注意

**本版只支持16:9游戏客户区**，允许约2像素取整误差。窗口标题栏不算客户区；显示器为16:9不代表窗口客户区一定是16:9。其他比例会暂停识别和自动配阵，提示调整游戏窗口。没有加入失败后扩区多轮OCR功能。

推荐1920×1080或2560×1440窗口化/无边框。真实1440p、多屏DPI、双龙及其他身份布局、傀儡和巅峰过渡仍有待补充实战的项目，详见TODO T42/T43；不要将本次截图回放当作全部布局已验证。

小程序的Windows控件读取可能波动、查询超时或攻略读取不完整，本次没有宣称解决这一历史限制。普通楚汉15秒、巅峰40秒是预算而非完成保证。数据统计可独立使用；攻略功能需用户登录微信并打开名将小助手。本助手不自动选将、出牌，不保证胜率，也不代表官方合作。
