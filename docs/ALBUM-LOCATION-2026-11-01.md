# 相册入口定位失败修复

## 证据

社区1.0.2、Win10 19045日志中8次配阵均成功切换小程序。5次约2.1秒报相册文本不可定位；另1次页面未确认，2次公开名单边界未确认。诊断包不含图片，不能断言按钮可见、微信升级或UIA延迟是唯一原因。

旧定位要求文字范围恰好返回一个矩形，空矩形或文字分段均直接失败。此前相册补点仅覆盖点击后没有出现文件框；入口定位抛错会绕过该恢复流程。

## 当前行为

1. 保留快速文字定位，接受相邻同一行的文字分段；校验几何、窗口范围与唯一位置。
2. 文字不可定位时查当前窗口下相册同名控件；不保留跨操作页面对象。
3. 仍失败、剩余时间至少4秒时，单请求仅一次懒加载已有OCR模型，通过绑定小程序HWND的WGC画面识别客户区下方80%区域。只接受高置信度、唯一的相册标签；不截桌面、不保存图片、不新增依赖。
4. OCR结束重新检查前台、模态框和客户区/窗框位置。点击仍经过原有窗口归属及遮挡检查；文件框真实出现才继续输入路径。
5. 单独的入口未就绪错误允许一次重新定位，取消/其他异常不吞掉。父进程原15/40秒时限保持。

正常成功路径不加载OCR；失败路径可能因模型冷启动增加耗时，不能承诺所有电脑更快。剩余时间不足时不给视觉兜底扩展预算。
