# 官方榜单自动复核（2026-11-06）

## 使用行为

启动与定时检查继续从官方 TapTap 榜单发现原图。新版本在整图 OCR 后，自动放大重读缺行、低置信度、两榜姓名不一致及词典外姓名对应的表格行；通过校验的模式自动启用，上一期保留供回退。其他模式失败不阻塞已通过的模式。

每行通常读 2 种放大尺度，最多 3 次；每图最多复核 40 行。名次必须从图中实际读出，不根据上下行补数字。可读结果冲突时不投票强行覆盖。低置信度名次须重复读到相同结果，并通过完整连续排名核验；胜率重读要求高置信度且一致。

词典外新姓名须在胜率榜和出场榜两个独立位置分别重复确认，每次姓名置信度至少 0.95。仅纳入通过校验的本期榜单，不自动扩展全局别名字典。继续检查两榜条数、姓名集合、重复、连续排名、胜率范围与排序、统计周期、来源和模式。

原始分块 OCR、行复核证据和最终校验结果均可追溯，解析缓存随算法版本失效。复核在后台进行，选将或配阵繁忙时逐次让出。此流程不增加游戏画面 OCR 次数。

## 仍需保留的边界

自动复核不是无条件自动批准。未知版式、大量缺行、可读结果冲突、来源/周期/玩法无法确认时，继续使用有效旧榜单。标题只写“巅峰身份”不能跨赛季自动视为“双龙争鼎”；只有本期官方图明确写出该模式，或经本期来源核验，才允许启用到该模式。

设置区分别显示自动更新、待核验和失败数量及原因。通过后清除相应待复核文件；检查和安装不重置当前局的攻略缓存，刷新词典也不清空连续帧确认。
