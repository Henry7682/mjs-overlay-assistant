# 隐私与反馈

本助手不自动上传诊断包，也不读取微信登录凭据、剪贴板内容或键盘输入文本。

数据浮窗使用游戏窗口截图、本地 OCR 和榜单。攻略查询需要名将小助手；普通楚汉会交给小程序完整游戏 PNG，画面可能包含昵称，小程序可能上传并保留其副本。助手不能删除第三方保存的副本。

1.0.0 默认开启本地故障画面记录，首次启动会说明。范围为绑定的游戏窗口和查询期间的小程序窗口，不截整个桌面；可在“反馈问题”页面关闭和清理。游戏最多1帧/秒，小程序最多2帧/秒，最近30秒保存在最多128MB的内存环形缓冲中。故障触发后保存已有的前30秒与后10秒可用素材，后台编码／写盘，队列满时丢诊断帧，不阻塞识别。故障包最多500MB、保留7天；日志最多100MB、保留14天。关闭后丢弃未保存帧，不再采集新图；已保存包需主动清除或到期清理。

日志记录版本、模式、局号、请求、OCR区域／姓名／置信度、阶段、筛选及超时原因、UIA调用类别和耗时、更新状态；不额外遍历整页控件。使用字段白名单并省略本机绝对路径、凭据字段。日志可能包含游戏武将名称及用户填写的问题描述，不能据此宣称完全匿名。

公开反馈包默认仅含结构化日志和环境摘要，不含图片。每份ZIP不超过20MB，包含文件SHA256和诊断编号；请保留所有分卷。含原图的私聊诊断包仍须逐张预览并勾选，允许直接在预览中拖动遮挡；大于单文件附件上限的图片会提示另行缩小后处理，不静默丢弃。突然崩溃或卡顿可能缺帧，抽样画面也不能重放Windows实时延迟；缺失证据会注明。

公开反馈默认不包含图片。添加图片前请逐张预览、遮挡昵称及聊天等信息。脱敏可能遗漏，请在提交前检查导出的文件。不要把令牌、密码、完整用户目录、私人聊天或未遮挡截图放进 GitHub Issue。

需要原始画面排查时，请加入 **QQ群 104720192**，联系群主／管理员后**私聊发送**；不要直接发到公开 Issue 或群文件。任何反馈都由你自行选择提交，不会后台自动发送。

维护者公开源码时排除私人日志、完整实战截图、配置、运行目录与旧 Git 历史；测试只保留不含用户信息的姓名条和界面标签裁片。官方榜单与游戏素材权利归相应权利人。
