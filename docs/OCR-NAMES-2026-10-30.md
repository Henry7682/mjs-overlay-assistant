# 普通楚汉四名武将 OCR 回放修复（2026-10-30）

适用版本：1.0.0 后未发布源码，分支 `codex/fix-ranked-nameplates`；不修改发行包、版本标签、用户配置或正在运行的助手。

## 复现与原因

用户提供两张普通排位楚汉八人候选截图。去掉窗口标题和桌面任务栏，实际客户区为 2559×1334。原尺寸与等比缩至 1920／1280 宽分别回放：

| 姓名 | 修改前证据 | 处理 |
| --- | --- | --- |
| 左棻 | 原图读对但置信度约 0.809；派生图出现左菜／左菲 | 加入受限字形补认 |
| 樊哙 | 原图读为樊哈，约 0.704；1280 宽仍读错 | 加入受限字形补认 |
| 卫玠 | 原图正确；派生图读为卫酚／卫盼，约 0.660／0.601 | 加入受限字形补认 |
| 司马相如 | 当前源码三个尺寸均正确；既有向上扩边能补齐首字 | 保留现有修复，新增用户截图回归；本轮未复现原报告的漏识别 |

因此不能把全部问题都归因于区域截断，也不能将当前源代码结果等同于用户正在运行的旧程序。尝试放大、阈值、对比度、竖转横等方法仍有稳定错字，不增加无图像证据的“左菜→左棻”等全局别名。

## 修改范围

仅普通楚汉、默认选将姓名区域、普通 OCR 未确认时启用局部字形核验。要求 OCR 为两个字且首字相符，全名图像相关度至少 0.94、上下各字至少 0.88、领先其他参考至少 0.12；仍需两帧确认。保留原始错读文本，并记录 `method=glyph_verified`，此时 confidence 是图像相关度而非 OCR 概率。

参考仅包含左棻、樊哙、卫玠的姓名和底色。三种尺寸均派生自本次原图，不是独立实战样本；只覆盖该种默认姓名条样式，不保证换皮肤、动画、真实 DPI 变化仍成功。其他模式、战斗、傀儡、自定义校准不使用这些模板；不改全局阈值或小程序流程。缺失参考文件时继续原 OCR。
