# 使用说明

以下说明对应 1.0.0 公开测试版。下载入口见[项目首页](../README.md)，已验证范围和待验收限制见[发布状态](RELEASE_STATUS.md)。

## 看武将统计

1. 使用窗口化或无边框游戏窗口。
2. 在助手设置中选择当前玩法；不确定时可手动固定模式。
3. 选将、战斗和偃师傀儡候选旁会显示胜率、胜率排名、出场排名。

普通排位楚汉改用**巅峰楚汉榜单**，顶部会标明来源和统计周期。两个楚汉模式共用此来源的更新／回退；原排位榜单仍单独保存。缺少来源时不使用其他榜单替代。

胜率前20，或胜率与出场排名同时前50，显示金色边框和“强势”。这只是榜单标记，不代表适合所有阵容。

## 小程序配阵

先登录微信，打开“名将小助手 → 一键配阵”，选“按强度／位置不限”。首次使用无需另行勾选；可在助手的“小程序配阵设置”中关闭查询或调整快捷键。普通排位会将完整游戏PNG交给小程序，可能包含昵称；小程序可能上传并保留图片。

- **普通排位**：确认进入选将后上传完整游戏 PNG，不等本地识别齐八人，自动操作最多15秒。
- **巅峰楚汉**：禁将名单中至少两名姓名连续确认、名单稳定约1秒后，通过小程序公开选择页输入已识别姓名，最多40秒。
- 键鼠输入不再直接取消查询。上传／填名中切到游戏会等待小程序回到前台，等待计入15／40秒预算；收到“提交完成”后可回游戏操作，后台读取结果。显式取消热键仍有效，助手不会替你禁将、选将或出牌。
- 攻略全部放入可滚动面板，保留小程序原始座次和说明。不能可靠区分亮星／灰星时不显示评分。
- 小程序公开列表未提供的武将会单独列出，继续查询其余武将；涉及未提交武将的组合不会凭空补齐。候选头像被底部工具栏遮住时自动滚动定位。
- 超时、中断或无法验证末尾时，保留已读内容并注明“不完整”。本地漏识别与攻略未读全会分别说明。

巅峰禁将结束以底部“选择本局要使用的武将／其他玩家选择中”提示和6～12人选将牌阵共同判断。进入选将后等待至少1.5秒，只用最初3秒内的可靠名单筛选一次；不完整时保留全部缓存，后续漏识别不会自动删攻略。可在设置中点“确认禁将后名单”人工确认。漏识别或想重新查询时使用配阵热键。弹出技能详情遮住牌阵时，不把技能文字当候选名单。

小程序需要人工确认时，请在小程序补选并确认，然后自行返回游戏。助手继续读取结果，最长等待90秒。最终名单与本地有冲突时，仅剔除涉及不一致武将的组合；不会因此丢弃全部有效攻略。

## 战斗攻略按钮

进入战斗后，攻略自动收起为“攻略”按钮。按钮可以拖动；点击展开后可滚动阅读“己方组合攻略”和“敌方组合攻略”，拖动标题栏移动面板，点“收起”恢复按钮。

- 普通排位己方仅查本局缓存；敌方两名主将和阵营确认后自动查询一次。失败不反复切窗，可主动重试敌方查询。
- 巅峰双方仅查本局缓存，战斗中不会切去小程序补查。
- 敌方漏识别不影响己方攻略；己方只确认一名武将时，展示含该武将的缓存参考，并注明实际组合待确认。
- 阵营不明时显示等待；缓存未找到、读取不完整、小程序明确无组合、尚未查询或查询失败分别提示。

按钮和面板会响应鼠标，武将统计标注仍鼠标穿透。切出游戏／最小化时隐藏，返回游戏后恢复；返回大厅、新局或切换模式／游戏窗口清空本局缓存。

## 设置与快捷键

托盘单击、双击或右键“打开设置”可打开设置；再次启动同一便携目录也会尝试唤出设置。

| 功能 | 新配置默认快捷键 |
|---|---|
| 重新配阵（战斗中重试敌方） | Ctrl+Alt+P |
| 展开／收起攻略 | Ctrl+Alt+D |
| 取消自动操作 | Ctrl+Alt+X |

升级保留已有快捷键，以设置显示为准。快捷键冲突会显示提示，可在配阵设置修改。
