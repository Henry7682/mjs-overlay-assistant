# 普通楚汉图片上传与逐名搜索

开发源码新增此设置，尚未发布到便携包。

默认使用截图导入。助手生成完整客户区PNG，通过小程序所属文件选择框的“文件名”输入框填入绝对路径并点击打开；不需要用户先选到截图所在文件夹。

如果相册能打开但无法继续：

1. 留意提示区分“临时截图不存在”“文件名输入框无法定位”“路径未写入”或“选择框未关闭”。导出诊断日志有助于区分文件权限与窗口控件差异。
2. 设置 → 小程序配阵设置 → 勾选“普通排位楚汉使用逐名搜索”并保存。默认不勾选，原设置保留。
3. 回到普通楚汉选将，等待本地确认8名候选。新一局自动查询；本局已尝试过时按Ctrl+Alt+P重查。

逐名搜索不上传截图，需本地姓名识别完整，仍最多15秒；可能只取得部分结果。它无法弥补本地漏名，可关闭开关回到截图方式。切换设置会取消正在进行的配阵；已有本局攻略保留，本地武将统计不受影响。

当前修复支持标准文件选择框的多层文件名控件，并检查文件路径与实际写入值。不会将文件夹搜索框当文件名输入框，也不会在不明确目标时盲目发送回车。其他电脑上的自定义文件选择器或特殊控件层级仍需要对应诊断证据，不能宣称全部适配。
