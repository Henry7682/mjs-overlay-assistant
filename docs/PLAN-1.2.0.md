# 1.2.0 产品与交付方案

目标：资源能被后续维护者复现更新；排位八人身份不再绑定赛季名称；玩家拥有不会被线上更新覆盖的个人组合库。

## 功能边界
- 排位八人身份使用稳定内部模式ID，兼容历史明刀暗箭榜单与校准；界面以“排位·八人身份”显示。入口必须同时有普通竞技场、楚汉相邻标签、明确高亮及有效右侧玩法文字。巅峰仍独立识别；不按八张牌推断模式。
- 官方榜单标题“8人身份/八人身份”可归入普通排位类别，含巅峰或其他明确玩法不能串用。具体季节规则差异不转化为额外胜率结论，始终显示统计周期。
- 个人组合存储在用户数据目录的独立文件。签名SQLite只读；覆盖、隐藏、个人新增在加载时合并。系统更新保留覆盖记录，原攻略撤下时已编辑副本仍保留并标注个人修改。
- 编辑器搜索武将/说明，新增、编辑、删除（来源攻略为隐藏）、恢复原版。支持两名不同武将、说明、独立站位评分、未提供评分。个人评分不冒充小程序评级；来源URL由原条目保留，不允许任意脚本链接。
- 保存原子写入并保留上次个人修改备份。校验错误阻止保存；损坏文件不静默清空。当前局固定快照，下一局使用修改；在线小程序结果不被本地编辑改变。
- 不做账号同步、多人协作编辑或向小程序上传个人攻略。

## 验收与发布
- 覆盖新增/修改/隐藏/恢复、基础库更新后覆盖保留、上游删除、错误站位/评分、HTML转义、坏文件及原子保存。
- 旧榜单模式兼容；改名入口不增加OCR轮次；普通/巅峰/其他玩法隔离。
- 完整测试、离屏编辑器验证、冻结自检、旧版升级配置和自定义数据保留。真实新赛季入口及Win10未覆盖项列TODO。
- 经PR及syntax/windows合并，干净v1.2.0构建；GitHub/Gitee新Release、匿名校验及签名更新通道。认证/上传受阻要明确记录，不能以准备文件冒充已发布。
