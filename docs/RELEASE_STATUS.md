# 1.0.0 发布状态

更新日期：2026-10-29。

GitHub 仓库先行开放，供代码审查和 Gitee 导入。当前为 **1.0.0 开发快照**，尚未发布 `v1.0.0` 标签、安装包或签名更新清单。源码中的版本号是目标版本，不代表发布验收已经完成。

## 已有功能

- 四模式武将统计、持续模式识别、校准与姓名纠正。
- 两种楚汉模式通过名将小助手公开界面查询配阵，保留部分结果与战斗攻略。
- 已接入诊断记录、反馈预览及旧数据导入的初步代码。
- 已有下载器、版本启动器、签名验证和回放工具的初步代码。
