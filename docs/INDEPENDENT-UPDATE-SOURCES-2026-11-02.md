# 两端独立发行发现与版本回退下载

本记录补充并更新 [此前慢速切换方案](DOWNLOAD-FAILOVER-2026-11-02.md)。状态：1.0.5 后源码，未发布。原签名清单和在线资产不变。

## 新规则

默认 Auto 分别保留 GitHub/Gitee 可验证候选，按版本从高到低尝试。某个来源不可用不阻止另一个来源检查；已安装 1.0.4、GitHub 1.0.6 下载失败或持续低速时，可改用 Gitee 1.0.5。已经安装 1.0.5/1.0.6 则不会降到 1.0.5。用户按 S 跳过终止整次下载，不继续切源。启动失败黑名单仍有效，签名、哈希、启动握手和数据备份规则不变。

两端 main 签名元数据共用约 8 秒检查预算，Gitee 发行发现另有最多约 8 秒；不宣称仍是合计 8 秒。下载总预算仍为启动器 180 秒、下载器 900 秒。有其他可用候选时，高版本失败后不反复重试至用尽总预算。持续低速判定沿用至少 8 秒、低于 256 KiB/s、剩余超过 1 MiB，阻塞读取仍受 15 秒上限。分卷也可在有备用候选时提前退出。全部失败启动旧版。

Gitee 通过匿名发行列表读取实际附件地址，不能依赖列表第一个条目为最新：现场列表顺序为 1.0.3 在 1.0.5 前。代码过滤非稳定数字标签并按数字版本排序，只尝试有完整附件路径、且高于已安装版的签名版本，最多保留三个国内候选。官方接口依据：[Gitee OpenAPI Swagger](https://gitee.com/api/v5/swagger_doc.json)。当前只扫描列表第一页（最多 100 条）；极大量历史发行仍是待扩展边界。

附件地址本身不是信任依据。只有名字匹配、属于本项目 Gitee 路径的 HTTPS 地址可补入候选；下载后必须匹配对应版本的签名大小/哈希，分卷及整包都校验，不跨版本拼接。缺少可信清单时跳过，不能仅凭 latest 页面执行文件。

## 每个 Gitee 发行要保存自己的签名依据

顺序：已验签同版本 main → 发行附件 release.json/release.sig → 不可变 release/history/版本.json/.sig。即使 main 已到 1.0.6，Gitee 1.0.5 仍可使用自己的签名文件。不要求两端最新版相同。

准备新发行时执行（PowerShell 5.1）：

```powershell
powershell -NoProfile -File release/prepare-mirror.ps1 -Manifest 待发布目录/release.json -AssetsDirectory 待发布目录 -OutputDirectory 新上传目录 -HistoryDirectory release/history
```

工具先验签和本地资产哈希，输出小于等于 90 MB 的完整资产或分卷，并额外复制两份原始签名文件。已有输出目录/不同内容历史不覆盖；不重新打包，不签名，不上传。历史文件经 PR 合入，Gitee 同步后可供兜底；推荐同时上传签名附件，使发行无需依赖 main 同步。当前 1.0.5 只有八个程序附件，缺少发行内签名附件，目前可使用仍为 1.0.5 的 main；本次只保存本地签名历史，不修改已发布资产。

上传后可省略手写地址表：

```powershell
python tools/verify_mirror.py --manifest 待发布目录/release.json --cache 验证缓存 --output 新清单.json
```

按确切版本从 Gitee API 发现附件，再匿名下载五种角色并校验，输出带地址且 mirror_verified=true 的候选清单。随后签名、PR 同步主通道，兼容旧启动器。原发行签名附件保持不变，内容哈希仍有效；新清单仅补充下载位置，不存在反复重打程序包的循环。发布门禁仍需实际下载证据，不因客户端能发现附件而跳过。

## 启动组件迁移

兼容下载库标记升为 3，PowerShell 入口标记协议 1。新版本提交成功后依次原子刷新外层 release/Release.ps1 和 launch.ps1，分别留 previous 备份；CMD 固定入口、公钥、用户数据不替换。旧版冻结程序取得新版后由新版应用补做迁移；源码运行不执行。中途断电至少保留兼容的旧入口/新库组合，下一次可重试迁移。

旧 1.0.5 首次下载新版仍受旧代码限制，不能远程保证未经升级的旧程序已经修好。安装/发布本次代码后才获得新行为。

## 验证

- 本地 PowerShell 5.1：GitHub 断网/持续低速/坏包转较低 Gitee 新版、跳过取消、拒绝降级、两端 main 失败仍用发行签名附件或历史、坏签名/版本不符/缺卷拒绝。
- 真实匿名 Gitee 冷下载：发现 1.0.5 两份程序分卷，约 77 秒下载、合并，校验大小和 SHA256 成功；另用 Windows PowerShell 5.1 从空缓存完整下载，约 139 秒通过，成品 158641473 字节。没有连接 GitHub 下载，不运行安装后的程序。此项不是无 VPN 网络环境的普遍保证，也不是 Win10 实测。
- 现有隔离启动器测试保留提交握手、配置不变、失败回退；完整套件结果见 TESTING。
- 待验收：包含修复的冻结包、旧版实际升级后入口迁移、Win10、真正无 VPN 网络低速换源。私人日志不公开。
