# 1.2.0 公开测试版

- 新增“编辑本地组合”：搜索、新增、编辑说明与各站位个人评分、隐藏组合、恢复原版。个人修改独立保存，资源自动更新不会覆盖，下一局使用。
- 普通排位八人身份不再以“明刀暗箭”为唯一入口名；沿用旧模式ID、校准与榜单兼容。普通竞技场相邻标签和选中状态共同确认，巅峰不串用。
- 新增维护者资源更新工作流，覆盖手动复核、双端签名发布、无VPN验证与回退。

使用：设置 → 编辑本地组合；每行站位对应两名武将及个人评分。未知站位两侧留空，评分也可留空。个人新增/编辑只作用于本地数据库来源，不更改在线小程序结果。
个人记录：用户数据目录 custom-guides.json；上一份备份 custom-guides.previous.json。不要直接编辑签名SQLite。当前对局采用原快照，修改从下一局生效。

公开测试版，不保证获胜。赛季入口整体改版仍可能需要适配；新的真实赛季入口、编辑后完整游戏实战、Win10仍需社区验证。既有官方榜单疑点复核与Windows UIA延迟限制保留。
