# 普通楚汉生僻姓名字形参考

九个 PNG 仅包含用户于 2026-10-30 提供截图中的“左棻”“樊哙”“卫玠”姓名与底色，不含昵称、人物头像、聊天、桌面或完整截图。每名三份分别来自原客户区画面及其等比缩放到 1920／1280 宽的派生图；它们不是三次独立实战采集。

用于普通排位楚汉、默认选将姓名条的受限后备核验。先有两个字的 OCR 结果及相同首字，再比较高通字形；全名相关度至少 0.94、上下两个字各至少 0.88、领先其他参考至少 0.12 才补认。相关度是图像相似度，不是 OCR 模型概率；诊断 `method=glyph_verified` 保留原始 OCR 错字。仍需两帧确认，不改全局 OCR 门槛。

普通 OCR 已可靠识别时不替换；战斗、巅峰、自定义校准及傀儡区域不使用这组模板。缺少文件时回退普通 OCR，不影响程序启动。模板只验证现有样式，其他皮肤／DPI／裁切和真实运行仍需验收，不能据此声称普遍解决所有生僻字。

原始图仅留私人研究目录，禁止将整个原图代替这些姓名条打包。字体和界面字形来自游戏画面，不主张其原创权利。

2026-10-30续修：允许姓名条附近极小平移（宽0.1%、高0.2%）补偿细笔画错位，原字形门槛不变。另有不依赖这些模板的三个姓名低分双读回退；见 `docs/OCR-RARE-FOLLOWUP-2026-10-30.md`，不会将局部错字加入全局词典。
