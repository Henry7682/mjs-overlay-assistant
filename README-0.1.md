# 名将统计助手 0.1.0

Windows 独立悬浮助手，用本机截图识别 Steam《名将杀》的选将姓名和八人战场姓名，显示官方明刀暗箭榜单的胜率、胜率排名、出场排名与周期。

## 运行

解压完整便携包，双击 `MjsOverlay.exe`。不需要安装 Python，不要单独移动 EXE，`_internal` 文件夹包含运行库与 OCR 模型。项目目录也可以双击 `start.cmd`。首次启动加载模型需要几秒。

1. 打开 Steam 名将杀，使用窗口化或无边框模式。
2. 助手自动连接唯一的游戏窗口；有多个窗口时，在设置中选一个。
3. 正常进入**明刀暗箭·8人身份**。连续两帧确认姓名后显示统计；首次出现通常约 1–2 秒。切出游戏、最小化或截图失败时隐藏标注。
4. 关闭设置窗口后助手继续留在托盘。双击托盘“将”图标打开设置，右键可暂停、隐藏或退出。

这是明刀暗箭的历史统计查询工具。请仅在该模式使用；它不推断身份、不推荐武将，也不判断某武将对当前阵容的实际强度。出场百分比没有可靠来源，因此只显示出场排名。

## 校准与纠正

默认配置适配已实测的 Steam 六选将卡牌排列及八人战场。不同 UI 布局、宽高比、卡牌数量或皮肤可能需要校准。

- 游戏前台停留片刻，再打开设置 → **校准区域／位置**。选将和战场分别保存。
- 每个区域只框一位武将的完整姓名，横排、竖排均可；不要包含国籍、技能描述和聊天。
- 切到“拖动标注位置”，可移动对应统计框。配置按场景与宽高比保存，等比缩放和窗口移动后继续适用。
- 低置信度或不完整姓名保留为“待确认”。在表中选中它，点击**纠正选中姓名**。纠正仅适用于当前槽位的当前识别文字，换将后失效。
- 自动场景判断失效时，可手动选择“选将”或“战斗”。离开对应界面后请切回自动。

## 文件与隐私

便携版设置、当前/上一版榜单、更新状态及日志放在 EXE 旁 `data`；目录不可写时使用 `%LOCALAPPDATA%\MjsOverlay`。源码运行使用 `runtime`。

游戏截图在内存处理，只有主动点击“保存诊断样本”时写盘。联网仅获取官方榜单，不上传截图。不注入游戏、不读取游戏内存、不模拟操作、不设置开机自启。

## 源码开发

Python **3.11 x64**。运行 `setup.ps1` 创建独立 `.venv`，按 `requirements.lock.txt` 安装固定版本；运行 `start.cmd` 启动。如果已有便携构建，`start.cmd` 优先运行便携版；直接运行 `.venv\Scripts\pythonw.exe main.py` 可启动源码。

```powershell
.venv\Scripts\python.exe -X utf8 -m pytest -q
.venv\Scripts\python.exe -X utf8 main.py --smoke smoke.json
powershell -File build.ps1
```

`--smoke` 主动禁止 Python 网络连接，验证内置模型和榜单，可追加本地游戏图片路径检查两帧识别。`--tray` 可仅启动到托盘。开发采样工具仅在明确运行时保存本地图片，不包含在正常启动流程中。

详细证据及未完成的硬件覆盖见 `TESTING.md`；第三方组件与模型来源见 `THIRD_PARTY_NOTICES.md`。
